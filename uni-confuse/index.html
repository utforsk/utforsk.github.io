About Unicode Confusables

What are confusables?

Unicode confusables (homoglyphs) are characters from different scripts that look identical or nearly identical to common ASCII characters. For example, Latin "a" (U+0061) and Cyrillic "\u0430" (U+0430) are visually the same but entirely different code points.

Why does this matter?

Confusables are used in phishing attacks, domain spoofing (IDN homograph attacks), bypassing content filters, and social engineering. A URL like "apple.com" can be forged using Cyrillic characters to look identical while pointing to a different server.

Security implications

  • Phishing domains that visually mimic legitimate sites
  • Bypassing keyword filters and blocklists
  • Impersonation in usernames and display names
  • Code obfuscation with look-alike identifiers
  • Evading plagiarism detection systems

How to use this tool

  • Type text on the left and see it confused live on the right
  • Similarity controls how close the look-alikes must be (5 = nearly identical, 1 = all variants)
  • Intensity controls what percentage of characters get replaced
  • Inspect mode analyzes pasted text for hidden confusables
  • Regenerate picks new random variants

Data source

Based on Unicode Consortium's confusables.txt (v8.0.0), part of Unicode Technical Standard #39.

Covers single-codepoint BMP confusables for printable ASCII. Characters that don't render in most browsers have been removed.
